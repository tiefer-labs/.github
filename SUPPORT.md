# Getting help

- **A question about one of our open-source repositories:** open an issue in that repository.
- **A bug:** open an issue using the bug report template.
- **A security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).
- **Interested in a pilot or a partnership:** write to [hello@tiefer.space](mailto:hello@tiefer.space) or use the contact form on [tiefer.space](https://tiefer.space).

We are a small team and answer as quickly as we can.
