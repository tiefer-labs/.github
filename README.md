# tiefer-labs/.github

This repository holds the public profile and the default community files for the `tiefer-labs` organisation on GitHub.

| File | Purpose |
|---|---|
| `profile/README.md` | The organisation profile shown on github.com/tiefer-labs |
| `SECURITY.md` | How to report a vulnerability privately |
| `CONTRIBUTING.md` | How to contribute, writing style, licence of contributions |
| `CODE_OF_CONDUCT.md` | Expected behaviour in our spaces |
| `ACCEPTABLE_USE.md` | What Tiefer may not be used for |
| `SUPPORT.md` | Where to ask for help |
| `ISSUE_TEMPLATE/` | Default issue forms for all repositories |
| `pull_request_template.md` | Default pull request description |

Files here apply to every repository in the organisation that does not have its own version.
